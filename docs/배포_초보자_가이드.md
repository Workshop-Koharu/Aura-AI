# Aura AI 배포 가이드

## 서비스 주소
- 웹사이트: https://aura.koharu.live
- 개인정보 처리방침: https://aura.koharu.live/privacy
- 이용약관: https://aura.koharu.live/terms

## 구성
- Vercel: 정적 웹 UI와 인증 게이트웨이
- Supabase: 인증 및 사용자 데이터
- Google Colab: 모델 학습·추론 런타임
- Google Drive: 데이터와 체크포인트 영구 저장
- Cloudflare Quick Tunnel: Colab API를 HTTPS로 연결

Vercel에서는 PyTorch를 실행하지 않습니다. 모델과 학습 코드는 Colab에서 실행합니다.

## Vercel 설정
프로젝트 Root Directory는 `web`, Framework Preset은 `Other`입니다. Build Command, Output Directory, Install Command는 비워 둡니다.

Production 환경변수:
- `SUPABASE_URL=https://imadhwyhsgfjdqxbkoyr.supabase.co`
- `SUPABASE_PUBLISHABLE_KEY`: Supabase Dashboard의 Publishable key
- `AURA_INFERENCE_URL`: Colab 노트북이 출력한 HTTPS 터널 URL
- `AURA_GATEWAY_SECRET`: Colab Secrets와 동일한 임의의 긴 문자열

변경 후 Vercel에서 Redeploy합니다. PostgreSQL 연결 URI는 브라우저나 프론트엔드에 넣지 않습니다. 현재 웹 게이트웨이는 Supabase Auth REST API를 사용하며 직접 PostgreSQL 연결을 하지 않습니다.

## Colab 노트북 열기
GitHub 저장소가 비공개이면 Colab의 GitHub API에서 404가 반환될 수 있습니다. 로컬 저장소의 `colab/Aura_Inference_Colab.ipynb` 파일을 직접 Colab에 업로드하거나 Google Drive에 업로드한 뒤 Colab에서 엽니다.

노트북 실행:
1. Colab에서 런타임 유형을 GPU로 선택합니다(제공되는 경우).
2. 왼쪽 Secrets 메뉴에 `AURA_GATEWAY_SECRET`을 등록하고 Notebook access를 켭니다.
3. 셀을 위에서부터 실행합니다. 재접속 시에는 **런타임 → 모두 실행**을 선택합니다.
4. 마지막 셀에서 `AURA_INFERENCE_URL`로 출력된 주소를 복사합니다.
5. Vercel의 `AURA_INFERENCE_URL`에 넣고 Redeploy합니다.

## 자동 재접속 동작
노트북의 watchdog은 Colab 런타임이 살아 있는 동안 API 또는 Cloudflare Tunnel 프로세스가 종료되면 다시 실행합니다. Colab 런타임 자체가 종료되면 그 안의 Python 코드도 실행될 수 없으므로 자동으로 런타임을 깨울 수는 없습니다. 새 런타임이 시작된 후 **런타임 → 모두 실행**을 누르면 Drive 데이터 연결, API 시작, 터널 시작을 다시 수행합니다. Quick Tunnel 주소는 세션마다 달라질 수 있어 Vercel의 `AURA_INFERENCE_URL` 갱신이 필요합니다.

## Google Drive 데이터
`My Drive/AuraAI/data` 아래에 `text`, `image_text`, `audio_text`, `checkpoints`, `tokenizer` 폴더가 생성됩니다. TXT 자료는 사용 권한이 있는 UTF-8 파일만 업로드합니다.

## 데이터베이스
Supabase 프로젝트 API 주소는 `https://imadhwyhsgfjdqxbkoyr.supabase.co`입니다. 이 프로젝트의 관리 연결 권한은 현재 연결된 Supabase 관리 계정에서 확인되지 않아 마이그레이션을 원격 적용하지 않았습니다. `supabase/migrations/202611050001_aura_core.sql`을 해당 프로젝트의 SQL Editor에서 실행해야 합니다.

제공한 PostgreSQL URI는 현재 웹 게이트웨이에서 사용하지 않습니다. 향후 직접 PostgreSQL 연결이 필요한 서버 코드가 추가되면 Vercel의 서버 전용 `DATABASE_URL` 환경변수로만 등록합니다. 브라우저 노출 변수로 만들면 안 됩니다.

## 제한
Colab은 상시 서버 호스팅이 아닙니다. 런타임이 종료되면 API와 터널도 중단됩니다. 상시 운영에는 전용 GPU 서버가 필요합니다.
