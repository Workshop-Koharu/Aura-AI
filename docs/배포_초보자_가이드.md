# Aura AI 배포 및 Google OAuth 설정 가이드

최종 서비스 도메인: https://aura.koharu.live

## 1. 현재 구성
- Vercel: 웹 UI와 인증 API 게이트웨이
- Supabase: 계정 인증 및 데이터베이스
- Google OAuth: Google 계정 로그인
- Google Colab: 모델 추론·학습 런타임
- Google Drive: 학습 데이터와 체크포인트
- Cloudflare Quick Tunnel: Colab API HTTPS 연결

Vercel은 모델 가중치나 PyTorch를 번들에 포함하지 않습니다.

## 4. Supabase Auth 설정
프로젝트 URL:
- https://imadhwyhsgfjdqxbkoyr.supabase.co

Supabase Dashboard → Authentication → URL Configuration:
- Site URL: https://aura.koharu.live
- Redirect URLs: https://aura.koharu.live/**
- 개발 중 로컬 주소가 필요하면 별도 허용 URL로 추가하고 공개 운영 시 제거합니다.

Authentication → Sign In / Providers → Google:
1. Google provider 활성화
2. Google OAuth Client ID 입력
3. Google OAuth Client Secret 입력
4. 저장

Google provider의 Callback URL은 위 OAuth redirect URI와 정확히 일치해야 합니다.

현재 연결된 Supabase 관리 도구에서는 이 프로젝트의 관리 권한이 확인되지 않아 OAuth provider 및 DB migration을 직접 변경하지 않았습니다. 이 단계는 Supabase Dashboard에서 직접 저장해야 합니다.

## 5. Vercel 환경변수
프로젝트 Production, Preview, Development에 다음 값이 설정되어야 합니다.
- SUPABASE_URL = https://imadhwyhsgfjdqxbkoyr.supabase.co
- SUPABASE_PUBLISHABLE_KEY = Supabase Dashboard의 Publishable key
- AURA_INFERENCE_URL = Colab에서 출력된 HTTPS Tunnel 주소
- AURA_GATEWAY_SECRET = Colab Secrets와 동일한 비밀 문자열

SUPABASE_URL과 SUPABASE_PUBLISHABLE_KEY는 Vercel에 반영했습니다. AURA_INFERENCE_URL과 AURA_GATEWAY_SECRET은 Colab 연결이 준비되면 등록합니다.

DATABASE_URL은 현재 웹 게이트웨이에서 사용하지 않습니다. 직접 PostgreSQL 연결을 추가할 때만 서버 전용 환경변수로 사용합니다. 이전 데이터베이스 프로젝트의 연결 문자열은 새 프로젝트에 사용하지 않습니다.

환경변수 변경 후 Vercel에서 Redeploy합니다.

## 6. Supabase 데이터베이스
SQL 마이그레이션 파일:
supabase/migrations/202611050001_aura_core.sql

Supabase Dashboard → SQL Editor에서 해당 파일의 SQL을 실행합니다. 실행 후 Table Editor에서 aura_profiles, aura_conversations, aura_messages, aura_api_keys 테이블이 생성됐는지 확인합니다. 각 테이블은 RLS 정책으로 사용자별 데이터 접근을 제한합니다.

## 7. Colab 실행 및 재접속
1. colab/Aura_Inference_Colab.ipynb 파일을 Colab에 직접 업로드합니다.
2. 런타임 유형에서 GPU를 선택합니다(사용 가능한 경우).
3. Colab Secrets에 AURA_GATEWAY_SECRET을 등록하고 Notebook access를 허용합니다.
4. 셀을 위에서부터 실행합니다.
5. 마지막 셀에 출력된 HTTPS 주소를 Vercel AURA_INFERENCE_URL에 등록합니다.
6. Vercel을 Redeploy합니다.

watchdog은 런타임이 살아 있는 동안 API와 Tunnel 프로세스가 종료되면 다시 실행합니다. Colab 런타임 자체가 종료되면 내부 코드도 멈추므로 새 세션에서 런타임 → 모두 실행을 해야 합니다. Quick Tunnel 주소는 세션마다 바뀔 수 있습니다.

## 8. Pretendard 폰트
