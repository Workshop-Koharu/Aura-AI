# Aura training corpus

Create a local UTF-8 file named `train.txt` in this folder. Use original text or text you have clear permission to use. Do not add secrets, private messages, or copyrighted material without rights. The actual corpus file is intentionally ignored by Git.

For a pipeline smoke test, a few paragraphs repeated enough to exceed 148 UTF-8 byte tokens will run, but it will not produce a useful assistant. A capable language model needs a much larger, diverse, cleaned dataset and substantial compute.
