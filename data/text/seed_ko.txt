Aura는 사전학습된 가중치를 사용하지 않고 무작위 초기화된 신경망을 데이터로 학습하는 연구 프로젝트다. 신경망은 여러 층의 계산으로 구성되며, 각 층은 입력에서 유용한 패턴을 추출한다. 학습은 예측 결과와 정답의 차이를 손실 함수로 계산하고, 역전파로 각 파라미터의 기울기를 구한 뒤 최적화 알고리즘으로 가중치를 조금씩 변경하는 과정이다. 학습 데이터의 품질과 양, 모델의 구조, 최적화 설정, 평가 방법은 모두 결과에 영향을 준다.

좋은 학습 데이터는 출처와 사용 권한이 명확해야 한다. 데이터 안에 중복 문서가 많으면 특정 문장을 외우는 현상이 생길 수 있다. 서로 다른 주제와 문체를 균형 있게 포함하고, 오류가 많은 문서와 개인정보는 제거해야 한다. 학습용 데이터와 평가용 데이터를 분리하면 모델이 보지 않은 자료에서 얼마나 잘 작동하는지 확인할 수 있다. 평가 데이터는 학습 과정에 섞지 않는다. 모델의 성능은 파라미터 수 하나만으로 결정되지 않는다. 데이터의 다양성, 토큰 수, 학습 시간, 계산 자원, 모델 설계와 평가 절차가 함께 중요하다.

컴퓨터 프로그램은 명령어와 자료구조를 이용해 문제를 해결한다. 변수는 값을 저장하는 이름이다. 함수는 입력을 받아 정해진 작업을 수행하고 필요하면 결과를 반환한다. 조건문은 참과 거짓에 따라 실행 경로를 선택한다. 반복문은 같은 형태의 작업을 여러 번 수행한다. 리스트는 순서가 있는 값의 모음이며, 딕셔너리는 키와 값의 쌍을 저장한다. 예외 처리는 예상하지 못한 오류가 발생했을 때 프로그램이 갑자기 종료되는 일을 줄인다. 테스트는 코드가 의도한 결과를 만드는지 자동으로 확인하는 절차다.

파이썬에서 함수는 def 키워드로 정의한다. 함수의 매개변수는 호출자가 전달하는 값을 받는다. return 문은 함수의 결과를 반환한다. 모듈은 재사용할 코드를 파일 단위로 묶은 것이다. 패키지는 관련 모듈을 디렉터리 구조로 정리한 것이다. 가상 환경은 프로젝트마다 파이썬 패키지의 버전을 분리한다. 의존성 파일에는 실행에 필요한 패키지와 버전을 기록한다. 버전 관리 시스템은 파일의 변경 이력을 저장하고 여러 개발자가 협력할 수 있도록 돕는다.

자료구조를 선택할 때는 필요한 연산과 데이터의 크기를 고려한다. 배열은 인덱스로 원소를 빠르게 조회할 수 있다. 연결 리스트는 원소를 삽입하거나 삭제하는 구조가 단순하지만 특정 위치를 찾으려면 순차 탐색이 필요하다. 해시 테이블은 키를 해시 함수로 변환해 평균적으로 빠른 조회를 제공한다. 스택은 마지막에 넣은 항목을 먼저 꺼내는 후입선출 구조다. 큐는 먼저 넣은 항목을 먼저 꺼내는 선입선출 구조다. 트리는 계층 관계를 표현하고 그래프는 정점과 간선으로 관계를 표현한다.

알고리즘의 시간 복잡도는 입력 크기가 커질 때 실행 시간이 어떻게 증가하는지 설명한다. 공간 복잡도는 추가로 사용하는 메모리의 증가를 설명한다. 선형 탐색은 처음부터 끝까지 값을 확인한다. 이진 탐색은 정렬된 데이터의 가운데 값을 기준으로 탐색 범위를 절반씩 줄인다. 정렬 알고리즘은 데이터를 일정한 순서로 재배열한다. 문제를 해결할 때는 먼저 입력과 출력, 예외 조건을 정의하고 작은 예시를 직접 계산한 뒤 알고리즘을 구현한다. 구현이 끝나면 정상 입력과 경계 조건, 잘못된 입력을 테스트한다.

컴퓨터는 이진수로 정보를 표현한다. 비트는 0 또는 1의 값을 가지는 가장 작은 정보 단위다. 바이트는 일반적으로 8비트다. 텍스트는 문자 인코딩 규칙에 따라 바이트로 변환된다. UTF-8은 여러 언어의 문자를 표현하는 가변 길이 인코딩이다. 이미지 파일은 픽셀의 색상 정보를 압축하거나 저장한다. 음성 파일은 시간에 따른 공기 진동을 디지털 샘플로 표현한다. 샘플링 주파수는 초당 측정 횟수이며, 비트 깊이는 각 샘플의 표현 정밀도와 관련된다.

이미지 인식 모델은 이미지의 픽셀에서 형태와 색상, 공간적 패턴을 학습한다. 패치 기반 인코더는 이미지를 작은 영역으로 나누고 각 영역을 벡터로 변환한다. 음성 인식 모델은 파형이나 스펙트로그램에서 시간에 따른 소리의 특징을 학습한다. 스펙트로그램은 시간과 주파수에 따른 신호의 에너지를 나타낸다. 이미지와 음성 인코더를 언어 모델과 연결하려면 서로 다른 표현 공간을 공통 벡터 공간으로 투영해야 한다. 이 연결도 충분한 짝 데이터와 학습이 필요하다.

수학에서 함수는 각 입력에 출력 하나를 대응시키는 규칙이다. 미분은 함수의 순간적인 변화율을 나타낸다. 기울기는 어떤 방향으로 움직일 때 함수 값이 얼마나 변하는지 알려준다. 최적화는 목적 함수의 값을 최소화하거나 최대화하는 방법을 찾는다. 경사 하강법은 현재 위치의 기울기를 이용해 손실이 작아지는 방향으로 파라미터를 갱신한다. 학습률이 너무 크면 최적점 주변에서 불안정해질 수 있고, 너무 작으면 학습이 매우 느려질 수 있다.

과학적 설명은 관찰 가능한 근거와 검증 가능한 절차를 바탕으로 해야 한다. 사실과 추측을 구분하고, 모르는 내용은 모른다고 표시한다. 수치나 인용을 제시할 때는 출처와 조건을 확인한다. 문제를 분석할 때는 여러 가능성을 비교하고 각 가능성을 지지하거나 반박하는 증거를 찾는다. 결론은 확인된 정보의 범위를 넘어서지 않아야 한다. 새로운 자료가 기존 결론과 다르면 설명을 수정한다.

프로젝트의 유지보수성을 높이려면 코드의 책임을 분리하고 인터페이스를 명확히 정의한다. 설정값은 코드 곳곳에 중복해서 쓰지 말고 한 곳에서 관리한다. 로그에는 작업의 상태와 오류 원인을 기록하되 비밀번호나 인증 토큰 같은 비밀 정보는 기록하지 않는다. 체크포인트는 학습을 중단한 뒤 이어서 진행할 수 있도록 모델 가중치와 최적화 상태, 학습 단계를 함께 저장한다. 체크포인트를 저장할 때 임시 파일을 사용하고 저장이 끝난 뒤 원자적으로 교체하면 손상 가능성을 줄일 수 있다.

네트워크 서비스는 요청과 응답의 형식을 명확히 해야 한다. HTTP 상태 코드는 요청의 성공 여부와 오류 종류를 전달한다. JSON은 객체와 배열, 문자열, 숫자, 불리언, null을 표현하는 데이터 형식이다. API는 프로그램이 다른 프로그램의 기능을 호출하는 규칙이다. 인증은 요청 주체를 확인하는 과정이며, 권한 부여는 확인된 주체가 어떤 작업을 할 수 있는지 결정한다. 비밀 키는 클라이언트 코드나 공개 저장소에 넣지 않는다. 로컬 전용 서비스는 외부 네트워크에 포트를 공개하지 않고 루프백 주소에 바인딩한다.

학습을 천천히 진행한다는 것은 단순히 학습률을 낮추는 것만을 뜻하지 않는다. CPU 코어 수와 메모리 사용량을 제한하고, 배치 크기와 시퀀스 길이를 조절하며, 각 업데이트 사이에 대기 시간을 둘 수 있다. 학습률은 모델이 한 번의 업데이트에서 파라미터를 얼마나 크게 바꿀지 결정한다. 체크포인트 주기는 작업을 복구할 수 있는 빈도와 저장 비용 사이의 균형을 맞춘다. 학습 과정에서는 손실이 감소하는지, 데이터가 균형 있게 사용되는지, 검증 결과가 개선되는지 함께 확인한다.

언어 모델은 앞선 토큰을 바탕으로 다음 토큰의 확률 분포를 예측하도록 학습할 수 있다. 토크나이저는 텍스트를 토큰 ID의 시퀀스로 변환한다. 바이트 기반 토크나이저는 모든 UTF-8 입력을 바이트 시퀀스로 표현할 수 있어 알 수 없는 문자에 대한 처리가 단순하다. 바이트 쌍 병합은 자주 함께 나타나는 인접 단위를 반복해서 하나의 토큰으로 합친다. 토큰 임베딩은 각 토큰 ID를 벡터로 바꾼다. 어텐션은 현재 위치가 다른 위치의 정보를 얼마나 참고할지 계산한다. 인과 마스크는 언어 모델이 아직 생성하지 않은 미래 토큰을 보지 못하도록 한다.

소프트웨어 품질은 기능이 작동하는지뿐 아니라 오류 처리, 보안, 접근성, 성능과 유지보수성을 포함한다. 테스트는 작은 단위의 함수 테스트, 여러 모듈의 통합 테스트, 사용자 흐름을 확인하는 종단 간 테스트로 나눌 수 있다. 재현 가능한 실험을 위해 데이터 버전과 설정, 코드 버전, 난수 시드를 기록한다. 모델을 비교할 때는 같은 평가 데이터와 같은 지표를 사용한다. 학습 손실만 낮아졌다고 실제 대화 능력이 좋아졌다고 단정할 수 없다.

Aura의 목표는 로컬에서 작동하는 독립적인 모델을 연구하고 점진적으로 개선하는 것이다. 현재 모델의 초기 파라미터는 무작위 값이며, 지식은 포함되어 있지 않다. 학습 데이터가 적으면 모델은 제한된 문장 패턴만 익힐 수 있다. 충분한 언어 능력과 이미지 이해, 음성 인식을 얻으려면 각 작업에 맞는 대규모 데이터와 별도의 평가 절차가 필요하다. 학습이 완료되었다는 표시는 실제 검증 결과가 확보되었을 때만 사용한다.
