Aura API

자체 생성형 모델을 애플리케이션에서 호출하기 위한 HTTP API입니다. API 키는 설정에서 발급하며, 생성 직후 한 번만 표시됩니다.

시작하기

  1. Aura 계정으로 로그인합니다.
  2. 설정 → API 키에서 키를 발급합니다.
  3. 키를 서버의 비밀 환경 변수에 저장하고 요청의 Bearer 토큰으로 전달합니다.
API 키를 브라우저 코드, 공개 저장소 또는 클라이언트 앱에 직접 넣지 마세요. 키가 노출되면 설정에서 즉시 폐기하세요.

기본 정보

항목값
Base URLhttps://aura.koharu.live
인증Authorization: Bearer YOUR_API_KEY
요청 형식application/json
응답 형식application/json

모델 목록

GET /v1/models

curl https://aura.koharu.live/v1/models \
  -H "Authorization: Bearer $AURA_API_KEY"

사용 가능한 모델 식별자를 반환합니다.

채팅 생성

POST /v1/chat/completions

요청 본문

{
  "model": "aura-from-scratch",
  "messages": [
    {"role": "system", "content": "Answer in Korean."},
    {"role": "user", "content": "안녕하세요. Aura를 소개해 주세요."}
  ],
  "max_tokens": 160,
  "stream": false
}

cURL 예제

curl https://aura.koharu.live/v1/chat/completions \
  -H "Authorization: Bearer $AURA_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "aura-from-scratch",
    "messages": [{"role":"user","content":"안녕하세요"}],
    "max_tokens": 160,
    "stream": false
  }'

응답 구조

{
  "id": "aura-local",
  "object": "chat.completion",
  "model": "aura-from-scratch",
  "choices": [{
    "index": 0,
    "message": {"role":"assistant","content":"..."},
    "finish_reason": "stop"
  }]
}

현재 API는 비스트리밍 응답을 지원합니다. 출력 길이는 1~512 토큰 범위에서 지정할 수 있습니다.

오류 코드

HTTP의미
400잘못된 요청 데이터
401API 키가 없거나 유효하지 않음
413요청 또는 첨부 파일 크기 초과
429요청 제한 초과
503추론 서버 또는 체크포인트 준비 안 됨
